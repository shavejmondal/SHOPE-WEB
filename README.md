# 🛒 ShopMart - Online Shopping Website

ShopMart is a modern and responsive e-commerce website built using HTML, CSS, and JavaScript with AI assistance. It provides a simple online shopping experience where users can browse products, add items to the cart, manage quantities, and proceed to a demo checkout.

## 🛒 How It Works

1. Browse the available products.
2. Click **Add to Cart** to add products.
3. Click the cart icon in the navigation bar to view your cart.
4. Increase or decrease the quantity of items.
5. Remove products from the cart if needed.
6. Click **Proceed to Checkout** to complete the demo purchase.
